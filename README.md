Este trabajo de Fin de Grado presenta el desarrollo de una aplicación web orientada a la gestión de reservas de pistas de pádel y la organización de partidas entre usuarios. El objetivo principal ha sido ofrecer una solución accesible desde cualquier navegador que facilite la reserva de instalaciones deportivas en municipios pequeños o entidades que no disponen de un sistema digital propio.
El desarrollo se ha estructurado mediante una metodología en cascada, abordando de forma secuencial el análisis de requisitos, el diseño de la arquitectura, la definición de la base de datos, la implementación de las funcionalidades y la realización de pruebas funcionales, de rendimiento y de usabilidad. Cada una de estas fases ha permitido construir progresivamente una aplicación organizada, coherente y adaptada a las necesidades planteadas.
Para su construcción se han utilizado tecnologías como Java para la lógica del servidor, JSP y servlets para la generación y gestión de las páginas web, MariaDB para el almacenamiento de información y JDBC para la conexión con la base de datos. Asimismo, se han empleado HTML, CSS, Javascripst y Bootstrap para el desarrollo de la interfaz, junto con Apache Tomcat como servidor de aplicaciones y GitHub para el control de versiones.
El resultado final es una aplicación web que permite registrar usuarios, iniciar sesión, consultar la disponibilidad de pistas, crear o unirse a reservas, gestionar participantes, registrar resultados y consultar clasificaciones. De este modo, el sistema constituye una base funcional para mejorar la gestión de instalaciones deportivas y facilitar la organización de partidas de pádel, manteniendo posibilidades de ampliación a futuras versiones.
